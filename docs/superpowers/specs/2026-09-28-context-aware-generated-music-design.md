## Problem Statement

插件虽然已经能通过 StarRouter/Suno 生成音乐，但 BGM、OP、ED 只保存自由文本 prompt 和 tags，无法证明音乐结合了当前剧集的剧情、人物、情绪曲线和剪辑节奏。无歌词的普通音乐生成也使用了 Suno 的自定义 `prompt` 字段，而官方接口推荐使用 `gpt_description_prompt`，容易把音乐方向误解为歌词或自定义内容。

## Solution

当用户明确需要 BGM、OP、ED 或音乐短视频配乐时，先从当前已选剧本、人物档案、导演本、分镜和制作计划形成结构化创作简报，再把简报编译成标题、音乐描述、风格标签和可选歌词。创作简报随 `audio-plan.music_tracks` 持久化并在付费生成前校验。StarRouter 适配器按官方 Suno 协议区分普通描述生成和自定义歌词生成。

## User Stories

1. 作为短剧创作者，我希望只在明确需要音乐时生成 BGM、OP 或 ED，从而避免未声明音乐和无谓费用。
2. 作为导演，我希望生成音乐结合剧情功能、当前冲突和主题，从而让配乐服务叙事而不是只贴风格标签。
3. 作为角色导演，我希望 OP/ED 的声音和歌词结合主角或群像弧线，从而保持人物主题连续。
4. 作为剪辑师，我希望音乐简报记录目标时长、情绪转折和剪辑节奏，从而能把完整生成结果裁切、循环或淡化到时间线。
5. 作为声音设计师，我希望音乐简报记录音色编制和人声方向，从而避免与对白、环境声和动作声争抢注意力。
6. 作为中文项目创作者，我希望歌词语言和叙述视角被明确记录，从而避免模型生成错误语言或人物口吻。
7. 作为插件用户，我希望无歌词 BGM 使用 Suno 的普通描述入口，从而降低描述被误当作歌词的概率。
8. 作为插件用户，我希望有歌词的 OP/ED 仍按自定义歌词入口生成，从而保留已批准歌词。
9. 作为成本承担者，我希望旧计划缺少创作依据时在付费调用前被阻止，从而不会为不可追溯的音乐付费。
10. 作为维护者，我希望旧音频计划被显式迁移为未决状态，而不是自动补造剧情和人物信息。
11. 作为制作团队，我希望音乐候选继续独立登记、试听、审核和选版，从而不因一次生成自动进入成片。
12. 作为复刻项目用户，我希望音乐复用和音乐生成仍受权利范围控制，从而不把参考音乐授权等同于可复制授权。

## Implementation Decisions

- 复用现有 `audio-plan.music_tracks`、`generate_music`、StarRouter `suno_music` 和任务账本，不新增第二套音乐服务。
- generated 曲目新增 `creative_brief`，包含叙事功能、剧情上下文、人物主题、分段情绪弧、剪辑节奏、声音编制、人声/歌词方向和目标时长。
- BGM、OP、ED 和 music-video 共用一个创作简报合同；内容按 purpose 变化，不建立四套 schema。
- `matched_shots` 继续表示允许进入的镜头范围；目标时长只是后期适配目标，不声称 Suno 能精确生成指定秒数。
- 普通描述或纯音乐请求发送 `gpt_description_prompt`；存在已批准歌词时发送 `prompt`。两者不会同时发送。
- 旧 generated 曲目缺少 `creative_brief` 时迁移为 unresolved 并取消 approved，不根据旧 prompt 反推剧情事实。
- Provider 返回完整候选；短 Demo、裁切、循环、淡入淡出和响度处理仍由后期完成。

## Testing Decisions

- 在 audio-plan 公共验证 seam 测试完整创作简报可通过、缺失或不完整简报被拒绝、旧计划迁移为 unresolved。
- 在 StarRouter provider seam 拦截请求体，验证无歌词请求使用 `gpt_description_prompt`，有歌词请求使用 `prompt`，且不会混发。
- 在现有集成自检中使用带创作简报的 generated OP，继续验证生成参数必须与当前 selected audio-plan 一致。
- 测试外部行为和请求合同，不断言内部辅助函数实现。

## Out of Scope

- 不增加新的音乐 Provider。
- 不自动发布生成结果，不自动选择候选，不自动覆盖时间线音乐。
- 不承诺 Suno 精确时长、精确卡点或特定歌手声纹。
- 不自动生成或复制受版权保护作品的旋律、歌词和声音。
- 不在本次实现自动完成母带、响度标准化或完整音乐审核评分。

## Further Notes

OP/ED 默认可以有人声；BGM 默认优先纯音乐，但最终由用户意图和 audio-plan 决定。提示词应描述可听的乐器、速度、节奏、动态和人声表演，不使用具体在世艺人或受保护作品作为模仿目标。
