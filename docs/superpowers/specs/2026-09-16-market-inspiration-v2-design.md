# 市场洞察与创作灵感闭环设计

日期：2026-09-16

状态：用户已确认

目标版本：0.9.0

## 1. 目标

在现有市场调研模块上补齐数据正确性、题材归一、灵感产物和项目引用，使排行榜数据既能用于市场判断，也能在不复制榜单作品的前提下为 Agent 提供可追溯的创作灵感。

## 2. 全局约束

- 只使用已保存的公开 Top 30 快照，不增加后台轮询、登录态采集或收益预测。
- 缺失指标必须保持缺失语义，不得按 0 分处理；机会分只按可用指标重归一权重。
- 原始题材标签必须保留为证据，分析使用规范题材；映射必须可解释。
- 市场事实、Agent 推断、创作假设、用户决定分层保存。
- 榜单作品的标题、人物关系和具体情节不得直接复制到创作产物。
- 市场引用必须包含报告 ID、快照 ID、筛选条件和内容摘要哈希。
- 市场灵感是显式可选输入，不加入所有项目的强制工作流，不覆盖来源事实、合规要求或用户已确认创意。
- 新增或修改的代码测试先行；新增注释使用中文。
- `.codex-plugin/plugin.json`、`.claude-plugin/plugin.json`、`.claude-plugin/marketplace.json` 版本统一为三段式 SemVer `0.9.0`。

## 3. 分析合同

市场报告升级为 `market-report.v2`：

- `topic_metrics` 中的需求、增长、新剧率和持久度允许为 `null`。
- 每个题材增加 `metric_coverage`，记录各指标有效观测数、总观测数和覆盖率。
- 机会分按当前可用正向指标的原始权重重新归一；拥挤度惩罚保持独立，不因缺失正向指标放大。
- 置信度同时考虑标签来源、样本量、分析范围和指标覆盖率。
- `coverage` 区分采集榜单集合与当前分析榜单集合；单榜筛选时平台覆盖分母使用分析集合。
- 趋势增加时间跨度及周期标签；不足 24 小时只标记为即时榜单变动，不称为日/周趋势。
- 报告增加规范题材共现、供需象限和平台 over-index 的结构化派生结果。

## 4. 题材归一

统一作品同时保存：

- `rawTopics`：来源原始标签。
- `topics`：规范题材。
- `provenance.topicMappings`：原始标签、规范标签和映射规则。

至少归并以下同义项：都市→都市日常、家庭→家庭伦理、霸道总裁→总裁、战神→战神归来、悬疑→悬疑推理、重生穿越拆分为重生与穿越、励志逆袭→逆袭。无法解释的标签保持原标签，不能静默丢弃。

## 5. 市场灵感产物

新增 `market-inspiration.v1` 文档：

- `report_ref`：报告 ID、快照 ID、生成时间、筛选条件、SHA-256。
- `signals`：结构化事实、置信度、证据引用和限制。
- `hypotheses`：派生信号、创作变换、前提、开场钩子、连续集引擎、差异化、制作适配、风险和验证问题。
- `decision`：已选/已拒假设及确认信息。
- `guardrails`：禁止复制标题、情节、收益承诺，并声明市场数据非权威创作事实。

新增 `ideate-drama-from-market` Skill。该 Skill 只读取指定已保存报告，产出 `market-inspiration.v1`；每个假设必须区分事实、推断和创作假设，并通过证据引用回链。

Brief 增加可空的 `market_inspiration_ref`，只引用用户已选择的灵感产物；Brief、Bible 与 Outline 不直接消费榜单作品清单。

## 6. Studio

- 题材热力矩阵用“题材 × 榜单”单元格呈现榜内百分位、有效样本数和无数据状态。
- 筛选候选值来自所选周期的未过滤报告，避免选项缩水。
- 增加灵感板：可选择 1–3 个题材、查看市场信号、生成本地灵感草案、选择候选并登记到项目。
- “用于项目”只保存报告/灵感引用，不自动改写项目题材。
- 新剧排名显示榜单名称；置信度显示中文并可解释。
- 删除遗留 `renderMarketLegacy`。

## 7. 验收

- 缺失热度、增长、新剧和持久度不会变成 0。
- 单榜筛选的分析覆盖率按单榜口径计算。
- 分钟级快照只显示即时变动。
- 同义题材合并且保留原始标签和映射证据。
- `market-inspiration.v1` 可验证、可保存、可回读，篡改引用可被摘要校验发现。
- Brief 能保存灵感引用，未显式引用时保持现有行为。
- Studio 可完成选择题材、生成候选、选择候选、用于项目的本地闭环。
- 市场测试、Studio 测试、插件审计、集成自检和三清单版本一致性检查全部通过。
