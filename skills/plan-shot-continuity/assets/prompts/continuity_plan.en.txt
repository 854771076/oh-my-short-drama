# Codex execution contract: continuity_plan

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from current selected project documents and reviewed assets.

Execution role: script supervisor and continuity director. Build shot-level spatial and state handoffs from the approved storyboard, director book, production plan, selected assets, and eligible previz contracts. Do not generate media.

[APPROVED PREVIZ DIRECTION CONTRACTS; EMPTY ARRAY WHEN NONE]
{approved_previz_contracts_json}

Return strict JSON only. The top-level fields are exactly `episode_key,source_versions,scenes,shots,unresolved,approved`. `source_versions` contains exactly the three vNNN versions `storyboard,director-book,production-plan`.

Each scene contains exactly `scene_key,coordinate_mode,axis_id,axis_description,camera_side,anchors,lighting_anchor`. Each shot contains exactly `shot_number,scene_key,camera_setup_id,start_state,end_state,transition_link,inherited_fields,allowed_changes,evidence`.

start_state and end_state contain exactly `actors,props,axis_id,camera_side,lighting_anchor`. An actor contains exactly `actor_key,zone,depth,facing,eyeline_target,screen_direction,entry_edge,exit_edge,posture,held_props`; a prop contains exactly `prop_key,zone,depth,state,held_by`. transition_link contains exactly `mode,source_shot_number,source_camera_setup_id,enabled,reason,required_provider_capability`.

Rules:
1. Default to `coordinate_mode=semantic`; zone and depth use screen-space and depth-layer semantics. Use `blender-world` only for a matching, approved Blender contract, and copy only coordinates that contract explicitly contains. Never estimate exact metric coordinates.
2. The first shot is independent with null source/capability fields and enabled=false. Compare the previous end_state with the current start_state, then call `recommendTailLink`; use previous-tail only for the same scene and camera_setup_id, the same axis/camera side, and no unexplained difference.
3. previous-tail has enabled=true, source_shot_number equal to the immediately preceding shot, source_camera_setup_id equal to that shot's setup, and required_provider_capability exactly `video.first-frame`. A camera change, axis crossing, scene change, or intentional discontinuity is independent.
4. inherited_fields lists only fields actually inherited. allowed_changes accepts only changes supported by the script, director book, or approved blocking; never use it to hide a conflict.
5. Never infer an undeclared prop, held-prop relationship, entrance, exit, absent character, or extra character. Put every unsupported state, coordinate, or change in unresolved; each item is exactly `{id,question,affects}`.
6. evidence contains at least one verifiable source. approved=false whenever unresolved is non-empty; approved=true only when every shot is continuous and every source version is currently selected.

No Markdown, explanation, API key, token, temporary URL, or path outside the project.
