# Codex 执行合同：agent_shot_variant_generate

本文件由所属 Skill 读取，用于约束 Codex 的输入、判断与输出；不是发送给外部文本模型的 system prompt。花括号字段是从当前项目已选资产组装的具名输入槽。

执行职责：专业的分镜图像生成助手。

======================================
【任务】
======================================

基于参考图片和变体指令，生成一个新的镜头图像。

新图像应保持以下一致性：
- 角色外观（服装、发型、体型）
- 场景环境（室内/室外、布置、光线基调）
- 整体美术风格

但需要按照变体指令改变：
- 镜头视角/角度
- 景别（距离）
- 构图方式

======================================
【⚠️ 构图缺陷修复纪律 - 强制】
======================================

1. 当变体来自构图缺陷修复时，一次只改变变体指令点名的那一个变量（主体位置、视线与留白、前后景层次与遮挡、光源方向与色温、动作拆分五者之一）；未被要求改变的主体位置、视线方向、前中后景内容、光源方向、屏幕方向与轴线、镜尾姿态必须与参考图及构图合同（visual_plan.composition / composition_contract / photographyPlan.composition）一致。创意变体（非缺陷修复）按 {target_shot_type}/{target_camera_move} 与变体指令改变视角、景别、构图或氛围，但仍受第 2–4 条约束：证据门禁、删除优先于美化、人数/身份/武器/遮挡/竖屏安全区等保持条款一律适用。
2. 删除优先于美化：原画面中在原文、已选场景/道具资产或已确认调度里找不到依据的雨、雪、雾、霓虹、镜面/水面反射、烟尘、门窗廊柱、武器、多余人物，必须移除或替换为只靠机位、调度、曝光成立的 composition-only 画面；禁止借生成变体把它们强化得「更电影感」「更有氛围」。
3. 需要 set_dressing、weather_atmosphere、action_blocking（含以 + 连接的复合证据）支撑的元素，依据只能来自原始镜头描述、角色/场景参考或已确认的变体指令；任一处都无据则不画。
4. 除变体要求外，多人画面的人数、站位、朝向、视线网和服色锚点保持不变；武器形制、持有关系和接触点不漂移；遮挡不盖脸、不盖关键动作；竖屏中面部双眼、关键道具与接触点位于中上安全区，底部字幕安全区保持干净，动势边缘至少留 10% 余量。

======================================
【⚠️⚠️⚠️ 全局画风一致性 - 强制铁律 - 最高优先级】
======================================

整幅画面所有元素必须使用完全统一的美术风格渲染，禁止任何风格混搭：
- 主角、配角、路人、群众、背景中任何人物，都必须与参考图中主角的画风完全一致（同一种描边、同一种上色、同一种渲染质感）
- 没有专属参考图的路人/配角/群众，严禁自行发挥成另一种画风，必须严格套用主角参考图的画风
- 场景、道具、天空、植被、建筑等所有环境元素必须与角色参考图保持同一渲染维度和同一质感
- 禁止角色是 2D 动漫风而背景是 3D 写实风；禁止人物是手绘风而道具是照片质感
- 如果参考图是 2D 手绘/动漫/漫画风格，则全图所有元素都必须是 2D，严禁出现任何 3D、CG、CGI、Blender、皮克斯/迪士尼 3D 卡通、虚幻引擎渲染、塑料质感、3D 建模感
- 如果参考图是写实/真人风格，则全图保持一致写实，禁止出现动漫化、卡通化人物
- 线条粗细、色块平涂/渐变、阴影软硬、高光处理全图统一
- 反 AI 味：禁止过度锐化、过度 HDR、过饱和、塑料皮肤、蜡像感、油腻质感、多余手指、畸形五官；保持自然笔触与克制色调，光影方向全图一致

======================================
【生成要求】
======================================

1. 严格按照【图像生成提示词】生成画面
2. 保持角色外观与参考图一致（服装、发型、体型）
3. 保持场景氛围与参考图一致（室内布置、光线、色调）
4. 改变镜头视角/景别/构图以匹配变体要求
5. 如果角色信息或场景参考中提供了固定站位 / 可站位置，必须保持人物仍然处于同一固定站位，不得随意换边、换前后景或漂移到其他区域
6. 画面中不出现任何文字、水印、编号、对白气泡
7. 输出图像比例: {aspect_ratio}
8. 遵守【构图缺陷修复纪律】：缺陷修复变体只改变变体点名的单一变量；创意变体可按 {target_shot_type}/{target_camera_move} 改变视角/景别/构图，但任何变体都必须把无证据的天气、霓虹、镜面、烟尘、门窗廊柱、武器或多余人物删除或替换为 composition-only 几何，不得为追求电影感而新增或强化
