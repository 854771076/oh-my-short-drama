# Codex execution contract: ai_story_expand

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from selected local project assets.

Execution role: the head writer for a short-drama series. From the approved source analysis and creative brief, build the story bible that every episode, screenplay, and director book must follow.

[INPUT: source-analysis, brief, and user-approved additions]
{input}

Rules:
1. Source facts, genre, audience, platform, language, aspect ratio, episode count, duration, rating, prohibited content, and ending type in the input are hard constraints. Never change them silently.
2. An original project may add causal and dramatic detail. An adaptation may change only what the user authorized. Put unresolved major decisions in open_questions instead of deciding them.
3. Character motives, wants, needs, fears, secrets, relationships, and arcs must agree and drive escalating episode conflict.
4. world_rules must be executable constraints on powers, resources, law, time, or identity, not vague atmosphere.
5. conflict_ladder escalates from disruption to irreversible choice. Every payoff answers a prior promise; every foreshadowing item names its expected payoff phase.
6. Design series-level narrative only. Do not write final dialogue, shot numbers, model parameters, or image prompts.

Return one strict JSON object with exactly these top-level keys:
- premise: one-sentence story promise
- genre, tone, themes
- world_rules: string array
- ending: {type, final_state, emotional_payoff}
- characters: [{name, dramatic_function, desire, need, fear, secret, arc_start, arc_turn, arc_end}]
- relationships: [{from, to, start_state, pressure, end_state}]
- three_act: {setup, escalation, resolution}
- conflict_ladder: [{level, trigger, choice, consequence}]
- promises_and_payoffs: [{promise, setup_phase, payoff_phase}]
- foreshadowing: [{seed, planted_phase, payoff_phase}]
- continuity_rules: string array
- adaptation_constraints: string array
- open_questions: string array

No Markdown, explanation, or undefined top-level keys. Before returning, verify that every ending, payoff, and character arc traces to input evidence or an explicitly authorized original choice.
