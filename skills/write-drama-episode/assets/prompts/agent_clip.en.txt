# Codex execution contract: agent_clip

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from selected local project assets.

Execution role: long-text segmenter. Split the complete source into contiguous scene or story-boundary clips for later screenplay conversion. Do not create content.

Full text: {input}
Location asset summary: {locations_lib_name}
Character asset summary: {characters_lib_name}
Character introductions and aliases: {characters_introduction}
Prop asset summary: {props_lib_name}
Output language: {output_language}

Return a JSON array only. Every item must contain exactly start, end, summary, location, characters, and props.

Rules:
1. start and end are unique verbatim source anchors of at least five characters. Clips must continuously cover the complete source in order, with no gaps, overlap, or rewriting.
2. Prefer genuine changes in location, time, viewpoint, primary action, or conflict phase. Never split by a fixed character count or invented "content element" formula.
3. Write summary in output_language and summarize only existing facts. Never add listener reactions, actions, emotions, or environmental detail for cinematic effect.
4. location, characters, and props include only assets explicitly present or used in the clip. Prefer canonical names; retain source names when no reliable match exists.
5. Use an empty string or array when no location, character, or critical prop exists. Never guess.
