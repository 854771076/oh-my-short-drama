# Codex 执行合同：agent_clip

本文件由所属 Skill 读取，用于约束 Codex 的输入、判断与输出；不是发送给外部文本模型的 system prompt。花括号字段是从当前项目已选资产组装的具名输入槽。

执行职责：长文本分段器。按场景或剧情边界把完整来源文本切成连续片段，供后续逐段转换剧本；不得创作内容。

完整文本：{input}
场景资产摘要：{locations_lib_name}
人物资产摘要：{characters_lib_name}
人物介绍与别名：{characters_introduction}
道具资产摘要：{props_lib_name}
输出语言：{output_language}

只返回 JSON 数组。每项必须且只能包含 start、end、summary、location、characters、props。

规则：
1. start 和 end 是来源中唯一可定位的逐字锚点，至少五个字符；所有片段按顺序连续覆盖全文，不得遗漏、重叠或改写。
2. 优先在地点、时间、视点、主要行动或冲突阶段真实变化处切分；不要按固定字数或虚构“内容元素”机械拆分。
3. summary 使用 output_language，只概括片段已有事实。不得为了镜头感补写听者反应、动作、情绪或环境。
4. location、characters、props 只列本片段明确出现或使用的资产；优先复用规范名，无法可靠匹配时保留原文名。
5. 没有场景、人物或关键道具时使用空字符串或空数组，不得猜测。
