# Codex execution contract: select_location

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from selected local project assets.

Extract reusable scene assets from the source. A scene is a stable physical space, not camera action or character performance.

[SOURCE]
{input}

Rules:
1. Extract only spaces where action occurs or which characters explicitly enter. Add rooms or zones as sub_locations only when a real containment relationship exists.
2. Give each scene three compositions with identical spatial structure. Preserve period, architecture, materials, fixed furnishings, depth layers, light direction, and at least three stable anchors.
3. Provide 2–6 available_slots located against anchors that appear in the descriptions; do not describe character action.
4. Default to an empty set. Only when the source explicitly requires public activity may has_crowd be true, using anonymous non-subject background crowds and never named characters.
5. Make only minimal neutral completions for missing dimensions, floors, weather, facilities, and decoration. Make generic locations controllable without inventing plot facts.

Return strict JSON only: {"locations":[{"name":"stable_scene_name_time","summary":"spatial purpose","has_crowd":false,"crowd_description":"","available_slots":["anchor-specific position"],"descriptions":["static description one","static description two","static description three"],"sub_locations":[]}]}.
Return {"locations":[]} when none qualify. Use standard JSON escaping and no extra fields.
