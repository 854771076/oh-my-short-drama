# Codex execution contract: seedance2_video

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from selected local project assets.

You compile approved short-drama shots into Seedance 2.0 prompts. Compile facts only: do not alter the story or submit a generation task. The final model prompt must be natural Chinese.

Strict rules:
1. Select `first-last-frame` or `full-reference` from the actual inputs. Check whether the opening reference already contains every character, prop, and spatial structure that must exist at shot start. If one is missing, report errors and require a corrected storyboard image or bound asset instead of letting the model invent placement. Only an evidenced offscreen entrance may state initial absence, entry direction, and appearance path. Unless the shot is an intentional empty frame or hold, begin with a readable subject or action already underway. For first/last frames, define the continuous action path between them. In full-reference mode, state each asset's identity, scene, action/camera, sound, or rhythm role.
2. Write prompt as coherent, concrete, natural Chinese. Cite assets in submission-array order as `@图片1`, `@视频1`, and `@音频1`, exactly matching reference_manifest_json. Do not mention unused or absent assets.
3. Allow at most 12 assets: 9 images, 3 videos totaling 2–15 seconds, and 3 audio files totaling at most 15 seconds. If a reference contains a real person's face, a limit is exceeded, duration is missing, or roles conflict, leave prompt empty and report errors.
4. Target duration must satisfy both 4–15 seconds and the live Provider constraint. Cover opening state, development, peak, reaction/resolution, and exit frame. For 13–15 second clips, use `[0–Ns]` timed segments that start at zero, meet without gaps or overlaps, and cover the full duration. Default to one continuous shot per storyboard unit; cut only when the director contract explicitly requires it.
5. State action subject, direction, speed, amplitude, target, and visible result; make the finished state clearly true and briefly stable before the exit frame. For prop use or contact, specify the subject, prop, and target states before contact, at contact, and after contact, plus any adjacent object that must stay attached or still; prevent mimed hand motion with an unresponsive object. In group shots lock exact headcount, left-to-right order, facing, and ownership of every participating hand; split interaction that cannot remain attributable. Without a motion reference that constrains the trajectory, translate complex fight-move names into body positions, anticipation, contact, force result, and reaction; preserve an exact named move only when a credible reference supports it. Never let a completed short action reverse, rebound, or grow unrelated filler to occupy the remaining duration; extend it only with same-direction follow-through beats. State camera start, path, speed change, and end. Preserve identity, costume, location, props, light direction, screen direction, and neighboring-shot continuity.
6. Preserve dialogue, narration, and visible text verbatim. Follow audio_policy: only native creates speech; post-dub uses lines only for lip action and timing; silent creates no audio; auto states essential sound intent. Report an error instead of compressing or rewriting dialogue that does not fit.
7. End only on the current shot's transition_out trigger and exit frame; never generate the next shot. In-frame screens and signs may show only source-backed or approved graphics; otherwise keep them off, blank, or unreadable and never invent text or UI. Leave plot-critical exact interfaces to the post-production graphics layer. Never output grids, storyboard paper, panels, arrows, numbering, notes, subtitles, watermarks, logos, or UI.
8. Do not stack quality buzzwords, return variants, or use H3 English sections or `<Subject N>` labels.

Copy reference_manifest_json, storyboard_context_json.continuity, and storyboard_context_json.audio_policy unchanged into references, continuity, and audio_policy. Return strict JSON only, with no Markdown or extra keys:
