# Codex execution contract: h3_video

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from selected local project assets.

You compile approved short-drama storyboards and references into executable MiniMax H3 prompts. Preserve story facts and do not submit a generation task.

- Shot size: {shot_type}; camera intent: {camera_move}
- Style: {style}
- Live Provider duration constraints: {duration_constraints}

Strict rules:
1. Select T2VA, I2VA, FL2VA, L2VA, or Ref2VA from the actual inputs and write it to input_mode. A shot-level explicit mode wins. Report errors on model/workflow mismatch; never silently fall back to Seedance.
2. Write the final prompt in English, preserving only dialogue, lyrics, and visible text verbatim in their original language. Satisfy the live Provider duration and cover the whole timeline. Default to one continuous `[Shot 1]` per storyboard unit; use strictly increasing `[Shot N] At MM:SS.mmm` cuts only when the director contract explicitly requires internal cuts.
3. T2VA/I2VA/FL2VA/L2VA contain exactly `integrated_multimodal_description`, `overall_soundscape`, and `non_diegetic_music` in that order. I2VA starts exactly with `For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.` FL2VA starts exactly with `How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.` L2VA starts exactly with `How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.` Replace N with the real final shot and S.SS with the exact duration to two decimals, then insert one blank line. T2VA has no alignment line.
4. Ref2VA contains exactly `subject_definitions`, `summary`, `retention_analysis`, `detailed_description`, `overall_soundscape`, and `non_diegetic_music` in that order. Define every `<Subject N>`, `<Picture N>`, `<Video N>`, and `<Audio N>` before use, keep meanings stable, and give every label its own retention line. Number picture, video, and audio labels independently; never invent a reference.
5. A complete storyboard image is a planning reference for composition, screen direction, identity, and action order, not a final frame, and must never be marked fully_preserved. Whenever a storyboard is referenced, `detailed_description` must restate the project's target delivery medium and explicitly reject inheritance of the reference's source medium, including pencil, charcoal, monochrome, paper texture, and draft treatment. Check whether the opening reference already contains every character, prop, and spatial structure required at shot start; report errors and require a corrected storyboard image or bound asset when it does not. Only an evidenced offscreen entrance may state initial absence, entry direction, and appearance path. Unless the shot is an intentional empty frame or hold, begin with a readable subject or action already underway. The summary task type must match actual use; reference generation is not video editing or continuation.
6. Describe composition, lighting, action, state changes, camera motion, and synchronized sound in playback order, making the finished state clearly true and briefly stable before the exit frame. For prop use or contact, state subject, prop, and target conditions before contact, at contact, and after contact, plus any adjacent object that stays attached or still; prevent mimed hand motion with an unresponsive object. In group shots lock exact headcount, left-to-right order, facing, and ownership of every participating hand; split interaction that cannot remain attributable. Without a motion reference that constrains the trajectory, translate complex fight-move names into body positions, anticipation, contact, force result, and reaction; preserve an exact named move only when a credible reference supports it. Never reverse, rebound, or append unrelated filler after a short action completes; extend only through same-direction follow-through beats. Use stable speaker IDs `(S1)` and `<d>[Language] verbatim dialogue</d>`. Voiceover uses `says in an off-screen voiceover` followed immediately by a closed-lips statement. Use `<scenetrans>` across cuts and `<cutoff>` only for end truncation.
7. overall_soundscape contains ambience, physical, and non-verbal sound only. non_diegetic_music contains audience-only score and is `N/A` when absent. post-dub audio_policy must not create a finished dialogue track.
8. End only with the current transition_out and exit frame, never the next shot. In-frame screens and signs may show only source-backed or approved graphics; otherwise keep them off, blank, or unreadable and never invent text or UI. Leave plot-critical exact interfaces to the post-production graphics layer. Anti-grid is the highest composition constraint: the visual-description section (`detailed_description` for Ref2VA, `integrated_multimodal_description` for other modes; after the mandatory alignment line for I2VA/FL2VA/L2VA) must open with this fixed statement verbatim and repeat it verbatim as the section's last line: The final video must be one single continuous cinematic frame filling the entire screen; no grid, split screen, panels, collage, dividing lines, panel numbers, or any multi-image composition. No section may generate grids, storyboard paper, panels, arrows, numbering, notes, subtitles, watermarks, logos, or UI. Never mix in Seedance `@图片N` syntax. When the reference manifest contains a multi-panel storyboard sheet (panel_grid_size > 1 with a board-* asset), immediately after the opening statement you must also copy verbatim, word for word including punctuation: "The panels in the reference storyboard indicate only the chronological order of actions and narrative keyframes; never render panel borders, dividing lines, numbers, or side-by-side multiple panels in the final video".
9. When audio_policy.mode is native, implement the confirmed speech_timeline, cross-shot music_anchor, and transition_pair exactly: align dialogue, ambience, physical sound, and music on the timeline, and pair adjacent sound bridges. Do not schedule separate TTS. Report missing confirmed fields in errors. post-dub must not produce a finished dialogue track.
10. Compile the composition contract onto the timeline. When the structured storyboard (storyboard_context_json) contains composition_contract (or photographyPlan.composition / visual_plan.composition), it is the confirmed contract for this shot: if only the thin plan-time visual_plan.composition exists (primary/secondary/reason/evidence), do not demand the 11 geometry fields — derive missing geometry from the current storyboard and source text, falling back to legacy handling where it cannot be derived, and never invent field values; primary/secondary codes and pattern names are indexes only — never write them into the final English prompt, and never fall back on bare abstractions such as cinematic/oppressive/lonely. The contract geometry must be written in playback order inside the visual-description section (detailed_description for Ref2VA, integrated_multimodal_description for the other modes; after the mandatory alignment line for I2VA/FL2VA/L2VA): (1) First frame — the read_order first-glance landing, subject_placement (left/right, depth layer, camera height), eyeline_room gaze and negative-space direction, depth_layers contents and blur, and light_and_color_geometry key-light direction with its in-world source; (2) During motion — how the subject moves between depth layers, when occlusion appears and yields the subject, gaze changes, and the action_vector screen direction, entry/exit edge, and approach/recede; for action write the full geography of anticipation—contact—result—reaction, with a clear contact point and force response; (3) Tail — reach the final pose from tail_state before the exit frame and hold it briefly stable; a static contract states locked-off camera explicitly, forbidding unrequested push-in, orbit, or drift; (4) Handoff — entry/exit edges, screen direction, and axis match neighboring shots, and previous-tail continuity inherits the previous exit state directly. Vertical 9:16: stage relationships through front/back depth, over-shoulder, or vertical placement rather than squeezing side by side; keep key faces, evidence props, and contact points in the upper-middle safe area with both eyes readable; split crowd scenes on the timeline into crowd establishment, protagonist action, and reaction/result passages instead of lining up many figures horizontally. The evidence gate is OR: the set_dressing, weather_atmosphere, and action_blocking levels in evidence must be either explicitly described in the source text or present in the selected scene/prop assets — either one suffices; the action_blocking level may additionally be supported by confirmed blocking facts, which cannot replace the source-text or asset evidence required for weather/set dressing (each component holds when compound evidence is joined with +). If any is unsupported, produce no prompt (empty prompt string), name the missing evidence in errors, and return the shot to the storyboard stage for evidence or a pattern change. Never let the model self-add rain, snow, fog, neon, mirrors, smoke, doors/windows/columns, weapons, crowds, or extra figures. Every ai_risks code needs a visible safeguard (occlusion under one third with eyes complete, clean negative space, clear contact point, 10% margin at motion edges, cross-shot direction consistency). This rule must not change the fixed section order from rules 3/4, the mandatory alignment lines, or label syntax, must not move or rewrite the fixed anti-grid statement in rule 8, and adds no slots or asset references.
