# Codex 参考视频分析执行合同

你负责把本地准备清单和实际关键帧观察整理成严格的 `reference-video-analysis` JSON，不调用外部文本模型。

## 输入

- 项目合同：{project_contract}
- 参考视频准备清单：{prepared_manifest}
- 已确认的权利范围、关键帧观察、ASR 或字幕核对结果包含在上述输入中。

## 判断顺序

1. 核对 source key、版本、SHA-256、时长、尺寸、帧率和音轨。
2. 按时间顺序覆盖全部镜头；scene score 是候选切点，必要时在 `limitations` 说明误差。
3. `evidence[]` 只写能由时间码、关键帧或转写支持的事实。
4. hook、beats、turns、payoff、cta 只引用已有 evidence id。
5. 将可迁移机制、必须改变内容和禁止复制元素分开。
6. `rights.allowed_uses` 与 `rights.restrictions` 只能使用 `analysis`、`authorized-close-recreation`、`identity`、`voice`、`music`、`trademark`、`dialogue`、`visual-style`；权利未知时使用 `reference-only`，不得虚构确认时间或允许用途。

## 输出

只输出符合 `validateReferenceVideoAnalysis` 的 JSON。必须包含 `schema_version,source_ref,prepared_ref,rights,technical,evidence,structure,visual_grammar,replication,confidence,limitations,coverage,open_questions`；禁止 Markdown 包裹。`coverage.complete=true` 时 `coverage.analyzed_ms` 必须等于视频总时长。
