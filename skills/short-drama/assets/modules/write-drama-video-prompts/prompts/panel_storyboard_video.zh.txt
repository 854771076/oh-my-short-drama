# Codex 执行合同：panel_storyboard_video

本文件由所属 Skill 读取，用于约束 Codex 的输入、判断与输出；不是发送给外部文本模型的 system prompt。花括号字段是从当前项目已选资产组装的具名输入槽。

执行职责：电影叙事视频提示词编辑。输入是一个故事版单元的故事版工作稿与结构化信息，包含 {panel_grid_size} 个按 {grid_layout} 排列、依时间推进的关键帧。这个单元可以对应一个连续镜头，也可以包含多个有剪辑依据的成片镜头。

【任务】
以结构化信息中 preImageGridPrompt.gridCells[].videoPrompt 为叙事骨架，按 cellIndex 升序整理成一条可直接用于视频生成的完整剪辑提示词。

{base_prompt}

镜头信息：

- 运镜：{camera_move}
- 项目视觉风格：{style}

【严格规则】
1. 必须保留每格的时间段、动作、事件顺序和因果关系；不得新增、删除、交换或改写剧情事件。
2. 台词必须逐字保留原文，嵌入对应时间段；不得改写、概括、补写或调整台词顺序。没有台词时不要虚构。
3. 可以优化镜头语言但不能改变剧情：识别故事版中景别、视角、场景或叙事重心变化的关键节点，明确写出必要的切镜、转镜、转场和特写；没有切镜依据的段落保持连续运镜。每次真正切镜必须标明时间点，并写成【镜头切换：原景别→目标景别；转场方式】；连续运镜不得误标为切镜。不得强制全程一镜到底，也不要机械地逐格切镜。
4. 保持角色身份、外貌、服装、场景、道具、光源方向、运动轴线和项目视觉风格连续。角色操作手机、终端或其他带功能面的道具时，功能面默认朝向操作者，镜头通常看到背面或侧面；只有主观镜头、屏幕特写、证据展示、交接或共同观看等明确叙事需要才让功能面朝向镜头。
【连续性】按 storyboard_context_json.continuity 执行：mode 为 independent 时，只根据已有信息简洁交代时间、地点、空间关系、关键光线和道具；为 previous-tail 时，从前镜尾部状态直接继续，继承人物位置、姿态、动作方向、道具持有、光向和轴线，不重新建立或重置场景。字段缺失时沿用当前分镜，不得猜测。
【声音策略】按 storyboard_context_json.audio_policy.mode 执行：native 可在对应时间段生成原文对白、旁白、环境声和动作声；post-dub 只生成环境声与动作声，对白和旁白仅指导表演及节奏，不得生成重复成品人声；silent 不生成原生声音；auto 只描述剧情必要的声音意图，不强制完整混音。画内对白由可见说话者做自然口型；画外对白不得让其他可见角色代说；旁白或内心独白不做说话口型，嘴部保持自然呼吸和当前表情。
5. 反宫格是最高构图约束：prompt 的首句必须原样写入固定声明，写完第 8 条结束画面后再另起一句原样重复该声明（一字不改，标点也不改）：「成片必须是单一连续的电影画面并铺满整个屏幕，严禁宫格、分屏、分框、拼贴、分割线、分镜编号或任何多画面构图」。紧接首句还必须原样写入：「源视频画面不得生成任何字幕、标题、标签、Logo、水印、UI文字或其他可读文字，所有获批文字只允许由后期图形层添加」。故事版纸张、白底、画框、宫格、时间码、文字、编号、箭头和导演批注只用于理解，不得出现在成片。当引用清单含多格分镜板（panel_grid_size>1 且引用 board-* 资产）时，紧接首句声明之后还必须原样写入（一字不改，标点也不改）：「参考分镜板中的画格只表示动作的时间顺序与叙事关键帧，禁止把画格边框、分割线、编号或多格并排构图拍进成片」。
6. 时长必须满足当前 Provider 的约束：{duration_constraints}。不得擅自向上取整或使用未声明档位；用清晰时间段描述画面、动作和镜头推进。
7. 不要堆砌重复画质词；只保留与镜头叙事和视觉连续性有关的信息。
8. prompt 最后必须是“镜尾转场【转场类型】”及一行当前镜头的结束画面；转场类型必须由当时的命中、遮挡、快速运动、强光、匹配动作、时间变化或段落结束提供依据。只描述当前素材如何结束，不得生成下一镜剧情。
9. 构图契约必须沿故事版节拍时间化编译。结构化故事版或 gridCells 的视频提示中若出现 composition_contract（或 photographyPlan.composition、visual_plan.composition），它是本镜已确认构图合同：若仅有 plan 期瘦合同 visual_plan.composition（只含 primary/secondary/reason/evidence），不要求 11 个几何字段齐全，缺失几何从当前分镜与原文推断、推断不出按旧分镜回退，不编造字段值；primary/secondary 的构图 code 与构图模式名仅作索引，禁止写进最终 prompt，也禁止只交「电影感」「压迫」「孤独」等抽象词；必须把合同几何沿 cellIndex 兑现——建立节拍（首帧）写清 read_order 第一眼落点、subject_placement、eyeline_room、depth_layers 与 light_and_color_geometry 的主光方向；动作节拍沿 action_vector 写逼近/远离、入画/出画边、遮挡让出，并按蓄力—接触—结果—反应排成全因果，接触点与受力结果各有清晰时间段；收束节拍落到 tail_state 的短暂稳定姿态（位置、朝向、剩余张力），静止合同显式写固定机位，禁止未要求的缓推、环绕或漂浮；板内有切镜时，切点两侧屏幕方向、出入画边与轴线一致，越轴必须有构图合同或 cinemaKnowledge 依据并给可读过渡；continuity 为 previous-tail 时直接继承前镜尾部。竖屏 9:16：关系镜用前后纵深、越肩或上下站位而非硬挤左右；关键脸、证据道具、接触点放在画面中上安全区且双眼完整可读；群戏按节拍/时间段拆成群体建立、主角动作、反应/结果，不横向平铺多人。证据门为 OR：evidence 中 set_dressing、weather_atmosphere、action_blocking 等级必须在原文明确描述或已选场景/道具资产中存在，二者任一即可；action_blocking 等级还可由已确认动作事实支撑，已确认动作事实不能替代天气/陈设所需的原文或资产证据（复合证据以 + 连接时逐组件成立）。任一不满足时停止编译、不产出 prompt（prompt 为空字符串），在 errors 中具名所缺证据，把该镜作为 unresolved 退回 revise-drama-storyboards 补证据或更换构图模式；禁止让模型自补雨、雪、雾、霓虹、镜面、烟尘、门窗廊柱、武器、群体或多余人物。ai_risks 逐风险给可见防控（遮挡不超过三分之一且双眼完整、留白区纯净、接触点清晰、动势边缘留 10%、跨镜方向一致）。本条内容写入第 5 条首句声明与末句声明之间的正文，不得移动或改写固定声明，故事版纸张、分框、箭头、编号等仍只作规划参考，不新增槽位或改变素材引用方式。
