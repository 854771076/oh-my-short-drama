# Codex execution contract: select_prop

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from selected local project assets.

Extract key props worth independent generation and cross-shot reuse.

[TEXT]
{input}

[EXISTING PROP LIBRARY]
{props_lib_name}

Include only movable physical objects with explicit narrative function, distinctive visual identity, and evidence of being carried, transferred, reused, or treated as key evidence. Exclude fixed facilities, ordinary furniture or tableware, one-off replaceable items, costume and makeup, abstractions, and objects without recurrence evidence. Omit uncertain items; normally return no more than three. Do not duplicate an existing stable prop identity.

description may contain only materials, colors, shape, structure, quantities, and decoration, with no people, hands, action, use, plot, camera, or background. summary identifies the object class only.

Return strict JSON only: {"props":[{"name":"stable name","summary":"object class","description":"static visual description"}]}. Return {"props":[]} if none qualify. Use standard JSON escaping.
