# Codex 视频复刻工作流执行合同

你负责把参考分析编译成可编辑、可重编译的声明式视频工作流，不调用外部文本模型。

## 输入

- 项目合同：{project_contract}
- 目标分集合同：{episode_contract}
- 参考视频分析：{reference_video_analysis}

## 设计规则

1. `slots[]` 声明 hook、host、topic、product、price、cta、language 及实际需要的媒体槽位。
2. `script.segments[]` 使用稳定 kebab-case id；每个 Media trigger 引用存在的 segment。
3. 画面、B-roll、贴纸和特效用 `segment_id` 与可选 `start_word/end_word` 锚定，禁止使用裸秒字段替代语义锚点。
4. Caption、Speech、Film 独立建模；改字幕样式不得强制重新生成视频素材。
5. `structure-only` 必须落实分析中的 forbidden elements 和 transform elements。
6. `authorized-close-recreation` 必须有非空 rights_basis 和 rights_scope，否则保留未决且不得批准；rights_scope 只能从 `identity`、`voice`、`music`、`trademark`、`dialogue`、`visual-style` 中选择，并且必须同时获 allowed_uses 允许且未被 restrictions 禁止。
7. `speech.mode` 默认 `native`（保留原声对白机制，逐句对齐由后续 ASR/强制对齐实现）；仅在 Provider 无原生音频能力或用户明确要求后配时才写 `post-dub`/`independent`。

## 输出

只输出符合 `validateRecreationWorkflow` 的 JSON，字段固定为 `schema_version,episode_key,analysis_ref,source_ref,rights_mode,rights_basis,rights_scope,slots,script,media_tracks,captions,speech,film,unresolved,approved`，禁止 Markdown 包裹。
