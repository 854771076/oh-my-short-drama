# Codex 执行合同：location_create

本文件由所属 Skill 读取，用于约束 Codex 的输入、判断与输出；不是发送给外部文本模型的 system prompt。花括号字段是从当前项目已选资产组装的具名输入槽。

把用户要求转成一个可复用的静态场景描述。

{user_input}

明确时代、空间结构、建筑与材质、固定陈设、前中后景、主光方向和稳定锚点。输入过泛时只补足可控布局。默认无人空镜；仅当用户明确要求公共活动时允许无名背景人群。不得写具名人物、剧情动作、机位运动、字幕、水印或质量词。

只返回严格 JSON：{"prompt":"完整场景描述"}。使用标准 JSON 转义。
