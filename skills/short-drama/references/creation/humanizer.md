# 自然化短剧剧本

读取已选剧本、brief、bible、outline、source-analysis，以及用户明确提供的语言样本。只处理表达与可表演性，不新增事实，不改人物身份、关系、关键动作、场次顺序、伏笔兑现、时长目标或已确认台词含义。忠实改编不得用“更自然”为理由改写原作事实。

逐场检查并修正：角色都说同一种话、台词解释动机、连续完整句缺少打断与潜台词、旁白重复画面、舞台说明像散文、机械三段式、泛滥的转折词和总结句、口号式金句、同义反复、刻意悬念、过量标题与括号。让每个角色的词汇、句长、回避方式和情绪泄露符合人物档案；保留必要停顿、沉默、抢话和未说完的话，但不为“人味”堆口头禅。

输出完整剧本新版本，不输出修改建议代替成稿。用 `project-store.mjs put-script` 写入下一个不可变版本并 `select-script`，禁止覆盖原稿；随后必须执行 `review-drama-script`。用户语言样本只作为风格参考，不能复制其中的个人信息或无关事实。

本 Skill 是插件内的短剧专用 Humanizer，吸收通用 Humanizer 的反模板化原则，但不套用百科写作规则，也不依赖外部 Skill。
