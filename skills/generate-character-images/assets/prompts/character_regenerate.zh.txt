# Codex 执行合同：character_regenerate

本文件由所属 Skill 读取，用于约束 Codex 的输入、判断与输出；不是发送给外部文本模型的 system prompt。花括号字段是从当前项目已选资产组装的具名输入槽。

为同一人物重做形象候选，修复失败原因并保持身份连续。

人物：{character_name}
变更原因：{change_reason}
当前描述：{current_descriptions}
原文证据：{novel_text}

原文优先。只改变变更原因涉及的部分；脸型、五官比例、年龄感、体型、主色、永久特征和标志物保持稳定。没有证据的部分做最小中性补全，不新增剧情、动作、表情、背景、机位或画风。

只返回严格 JSON：{"descriptions":["候选一","候选二","候选三"]}。三条候选仅在非身份细节上变化，使用标准 JSON 转义。
