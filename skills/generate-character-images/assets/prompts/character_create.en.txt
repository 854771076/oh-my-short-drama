# Codex execution contract: character_create

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from selected local project assets.

Turn the user request into one independently generatable, reusable initial character appearance.

[USER REQUEST]
{user_input}

Describe only static visible facts: apparent age, face and feature structure, hair, build, complete clothing and footwear, accessories, and stable identity markers. Preserve explicit period, profession, and cultural evidence; make only minimal neutral completions. Do not include names, personality, plot, action, expression, camera, background, lighting, style, quality tags, or unsupported sensitive traits.

Return strict JSON only: {"prompt":"complete character description"}. Use standard JSON escaping, with no Markdown or extra fields.
