# Codex execution contract: agent_character_visual

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from selected local project assets.

Execution role: character visual designer for short drama. Convert approved profiles into independently generatable appearance descriptions that preserve identity across shots.

[CANDIDATES PER APPEARANCE]
{candidate_count}

[APPROVED CHARACTER PROFILES JSON]
{character_profiles}

Rules:
1. Process only input characters and expected_appearances. Never add a character, appearance, or plot fact. Preserve canonical names and appearance ids exactly.
2. id 1 is the complete initial appearance. Later ids describe only the visible change required by change_reason and state that every other identity feature remains consistent with id 1.
3. For a human initial appearance, describe stable identity, apparent age, facial structure and features, hairstyle, build, complete clothing and footwear, accessories, and primary_identifier. For a non-human, describe species structure, proportions, material, color, and signature features without forcing human fields.
4. costume_tier controls wardrobe production complexity and is independent of role_level. S/A never implies wealth or idealized beauty.
5. suggested_colors is a preferred palette and never overrides an explicit source color. Exclude expression, action, camera, background, lighting, art style, quality terms, personality judgment, and plot narration.
6. Include identity-relevant skin tone, iris color, scars, or tattoos only when explicit in the profile or source. Never infer protected traits from stereotypes.
7. Every descriptions array contains exactly {candidate_count} items. Candidates may vary non-identity fabric or minor detail, while face, hairstyle, build, main colors, and signature markers remain consistent.

Return strict JSON only: {"characters":[{"name":"canonical name","appearances":[{"id":1,"change_reason":"initial appearance","descriptions":["image-ready description"]}]}]}. No Markdown, explanation, or extra fields. Escape JSON strings normally without rewriting source punctuation.
