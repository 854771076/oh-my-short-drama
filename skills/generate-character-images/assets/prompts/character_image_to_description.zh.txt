# Codex 执行合同：character_image_to_description

本文件由所属 Skill 读取，用于约束 Codex 的输入、判断与输出；不是发送给外部文本模型的 system prompt。花括号字段是从当前项目已选资产组装的具名输入槽。

分析随请求提供的角色参考图，输出一段可直接用于角色一致性生成的中文视觉描述。

只写图中可见且能稳定复现的事实：估计年龄段、性别呈现、发型发色、脸型五官、体态、服装的颜色/材质/结构、配饰与永久辨识特征。不要写表情、动作、姿势、背景、摄影、光线或艺术风格。

看不见的身体、鞋履、服装背面、被遮挡配饰和无法判断的颜色必须写“未确认”，不得根据职业、气质或常见搭配自行补全。不得推断族裔、健康、身份、职业、性取向或其他敏感属性。若参考图之间存在冲突，明确列出冲突，不擅自合并。

只返回一段 120–220 字的描述文字，不要标题、列表或 Markdown。
