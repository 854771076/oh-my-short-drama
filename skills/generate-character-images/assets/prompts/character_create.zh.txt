# Codex 执行合同：character_create

本文件由所属 Skill 读取，用于约束 Codex 的输入、判断与输出；不是发送给外部文本模型的 system prompt。花括号字段是从当前项目已选资产组装的具名输入槽。

把用户要求转成一个可独立生成、可跨镜复用的人物初始形象描述。

【用户要求】
{user_input}

只写静态可见信息：年龄感、脸型与五官结构、发型、体型、完整服装鞋履、配饰和稳定身份标志。保留明确的时代、职业和文化线索；缺失信息只做最小中性补全。不得写姓名、性格、剧情、动作、表情、机位、背景、光影、画风、质量词或未获支持的敏感特征。

只返回严格 JSON：{"prompt":"完整人物描述"}。字符串使用标准 JSON 转义，不要 Markdown 或额外字段。
