# Codex execution contract: character_image_to_description

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from selected local project assets.

Analyze the character reference image supplied with the request and return one English visual description suitable for identity-consistent generation.

Describe only visible, repeatable facts: estimated age band, gender presentation, hair shape and color, facial structure, build, clothing color/material/construction, accessories, and permanent identifying features. Exclude expression, action, pose, background, cinematography, lighting, and art style.

Mark unseen body regions, footwear, garment backs, occluded accessories, and uncertain colors as "unconfirmed". Never complete them from occupation, personality, or common fashion assumptions. Do not infer ethnicity, health, identity, occupation, sexual orientation, or other sensitive traits. If references conflict, state the conflict instead of silently merging it.

Return one 100–180 word paragraph only, with no heading, list, or Markdown.
