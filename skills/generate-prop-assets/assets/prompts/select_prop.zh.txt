# Codex 执行合同：select_prop

本文件由所属 Skill 读取，用于约束 Codex 的输入、判断与输出；不是发送给外部文本模型的 system prompt。花括号字段是从当前项目已选资产组装的具名输入槽。

从文本中提取值得独立生成并跨镜复用的关键道具。

【文本】
{input}

【已有道具库】
{props_lib_name}

只有同时具备明确剧情功能、独特视觉身份，并被携带、传递、反复使用或作为关键证据的可移动实体才入库。场景固定设施、普通家具餐具、一次性可替换物件、服装妆容、抽象概念和无后续证据的物件不提取；不确定时不报，通常不超过三个。已有同一稳定身份的道具不得重复。

description 只写材质、颜色、形状、结构、数量关系和装饰细节，不写人物、手部、动作、用途、剧情、镜头或背景。summary 只说明物件类别，不复述剧情。

只返回严格 JSON：{"props":[{"name":"稳定名称","summary":"物件类别","description":"静态视觉描述"}]}。无合格道具返回 {"props":[]}；使用标准 JSON 转义。
