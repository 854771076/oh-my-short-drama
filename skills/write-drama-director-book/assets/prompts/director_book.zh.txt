# Codex 执行合同：director_book

本文件由所属 Skill 读取，用于约束 Codex 的输入、判断与输出；不是发送给外部文本模型的 system prompt。花括号字段是从当前项目已选资产组装的具名输入槽。

执行职责：短剧导演。把已选剧本转成场次级导演执行合同，解释每场“为什么这样拍”，但不要提前拆成最终镜号。

{project_contract}

【故事圣经】
{story_bible}

【已选单集剧本】
{screenplay}

只返回严格 JSON：{"episode_key":"...","source_script_version":"...","scenes":[...],"continuity_ledger":[],"open_questions":[]}。

每个 scenes 项必须包含：scene_key、source_scene、dramatic_objective、beats、subtext、performance_direction、blocking、eyelines、axis_rule、camera_strategy、lighting_and_color、sound_plan、transition_in、transition_out、continuity_state、asset_requirements、prohibited_changes。

规则：
1. 每个场次逐一对应剧本场景并完整覆盖；不得新增剧情事实或改写逐字台词。
2. 先从场尾的信息、关系或权力变化反读本场共同事件，把所有在场人物（包括沉默者）纳入 dramatic_objective；它描述本场正在发生的关系行动，不写成主题口号或观众效果。
3. performance_direction 按角色写清参与共同事件的个人动机、当前目标、阻力、策略、倾听/视线对象和有来源证据的身体通道。沉默角色也要有可表演任务，例如判断、隐瞒、等待破绽或维持局面；若剧本存在持续工作或生活动作，让角色通过该动作完成策略，停止动作可作为节拍重音。subtext 说明言语与真实意图的差距，不用空泛情绪代替行为，也不为凑字段补造动作。
4. blocking、eyelines 和 axis_rule 必须互相一致，明确人物起止位置和运动方向；接近、退让、占据空间或地位翻转必须对应具体节拍与关系变化，不做无动机走位，也不使用模型无法稳定兑现的伪精确距离。
5. sound_plan 区分对白、旁白、环境声、动作声和 BGM 意图，但不伪造最终音频参数。
6. continuity_ledger 记录跨场持续的人物造型、道具状态、空间方向、时间和光线。人物离画时还要记录离画边、最后可见姿态、运动方向和持物状态，保留到其下一次入画或场景明确重置；重新入画方向必须与该记录和既定轴线相容。
7. 涉及剧情含义、人物关系或声音策略的新决定写入 open_questions。

禁止最终镜号、生成模型、费用、图片提示词、Markdown 和解释。
