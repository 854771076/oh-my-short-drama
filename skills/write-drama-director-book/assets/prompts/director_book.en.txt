# Codex execution contract: director_book

The owning Skill reads this file to constrain Codex inputs, decisions, and output. It is not a system prompt sent to an external text model. Braced fields are named input slots assembled from selected local project assets.

Execution role: short-drama director. Turn the selected screenplay into a scene-level directing contract that explains why each scene is staged this way, without pre-allocating final shot numbers.

{cinematography_vocabulary}
The list below is the per-shot composition vocabulary; the director book uses it only at scene level: choose just 1–3 codes per scene as scene-level composition motifs, never allocate compositions shot by shot or demand mechanical shot-by-shot reuse downstream. The full code-name mapping, per-pattern evidence floors, and vertical-screen rules live in references/controlled-vocabulary.json (cinematography.compositionPatterns) and references/director-composition.md; this contract uses only the pattern codes.

Return strict JSON only: {"episode_key":"...","source_script_version":"...","scenes":[...],"continuity_ledger":[],"open_questions":[]}.

Every scenes item contains: scene_key, source_scene, dramatic_objective, beats, subtext, performance_direction, blocking, eyelines, axis_rule, camera_strategy (including composition_motifs), lighting_and_color, sound_plan, transition_in, transition_out, continuity_state, asset_requirements, prohibited_changes.

Rules:
1. Map every scene to the screenplay and cover it completely. Never add plot facts or rewrite verbatim dialogue.
2. Read backward from the scene ending's change in information, relationship, or power to name one shared scene event. dramatic_objective must include every present character, including silent ones, as a participant; it is a playable relational action, not a theme or intended audience effect.
3. For each character, performance_direction states their motive for participating in that event, current objective, obstacle, tactic, listening/eyeline target, and an evidenced physical channel. Give silent characters a playable task such as assessing, concealing, waiting for an opening, or protecting the situation. When the screenplay already contains ongoing work or daily business, let the tactic travel through it and use an evidenced interruption as a beat accent. subtext states the gap between words and intent. Never replace behavior with vague emotion or invent actions to fill fields.
4. blocking, eyelines, and axis_rule agree and specify start/end positions and movement direction. Tie approach, retreat, occupation of space, and status reversal to a specific beat and relationship change; avoid unmotivated movement and false measurement precision the model cannot render reliably.
5. camera_strategy must include composition_motifs: an array of 1–3 scene-level composition motifs, and every motif must be an object of exactly this shape: {"code":"...","narrative_job":"...","variation":"...","payoff":"...","axis_constraints":"..."}. code must be a controlled vocabulary code only (composition.basic.* / composition.film.* / composition.action.* / composition.character.*); narrative_job states the motif's narrative job; variation states how it changes as the shared scene event develops (for example one framing used differently at entry, reversal, and scene end); payoff states how it resolves at scene end; axis_constraints states the constraints it sets on neighboring shots' screen direction, eyelines, and axis. Motifs are scene-level visual intent, not a shot list or a shot-by-shot composition assignment; never pre-allocate final shot numbers in the director book or demand mechanical rotation downstream. Choosing a code commits to its evidence floor: composition-only is realized through camera position, scale, blocking, and exposure alone without adding objects or weather beyond the source or assets; set_dressing requires doors, windows, mirrors, columns, long tables, neon, weapons, or similar to exist in the screenplay description or scene/prop assets; weather_atmosphere requires rain, snow, fog, backlight, or dual-color-temperature sources supported by the source text, scene time, or assets; action_blocking requires conflict, pursuit, encirclement, or group movement established by the screenplay or directing blocking; a compound value joined with + requires every component. When evidence is missing, switch to a lower-floor motif rather than inventing dressing, props, or weather.
6. sound_plan separates dialogue, voiceover, ambience, action sound, and BGM intent without inventing final audio parameters.
7. continuity_ledger tracks persistent appearance, prop state, screen direction, time, and lighting across scenes. When a character exits frame, also record the exit edge, last visible posture, movement direction, and held props until that character re-enters or the scene explicitly resets; re-entry must agree with that record and the established axis.
8. Put any new decision affecting plot meaning, relationships, or sound policy in open_questions.

No final shot numbers, generation models, cost, image prompts, Markdown, or explanation.
