# Codex Video Recreation Workflow Execution Contract

Compile the reference analysis into an editable and recompilable declarative video workflow. Do not call an external text model.

## Inputs

- Project contract: {project_contract}
- Target episode contract: {episode_contract}
- Reference video analysis: {reference_video_analysis}

## Design rules

1. Declare hook, host, topic, product, price, CTA, language, and required media placeholders in `slots[]`.
2. Use stable kebab-case ids in `script.segments[]`; every Media trigger references an existing segment.
3. Anchor footage, B-roll, stickers, and effects to `segment_id` plus optional `start_word/end_word`. A raw seconds field cannot replace a semantic anchor.
4. Model Caption, Speech, and Film independently; a caption style edit must not force media regeneration.
5. A `structure-only` workflow must apply every forbidden and transformed element from the analysis.
6. `authorized-close-recreation` requires non-empty rights_basis and rights_scope; otherwise keep it unresolved and unapproved. Choose rights_scope only from `identity`, `voice`, `music`, `trademark`, `dialogue`, and `visual-style`; every scope must be allowed by allowed_uses and absent from restrictions.

## Output

Output only JSON accepted by `validateRecreationWorkflow`, with exactly `schema_version,episode_key,analysis_ref,source_ref,rights_mode,rights_basis,rights_scope,slots,script,media_tracks,captions,speech,film,unresolved,approved`. Do not wrap it in Markdown.
